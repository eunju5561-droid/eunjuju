# 배포

아래 순서대로 실행해줘.

## 1단계 — 변경 파일 확인
`git status`와 `git diff --stat`를 실행해서 변경된 파일 목록을 확인하고, 변경사항을 간단히 요약해줘.
변경사항이 없으면 "배포할 변경사항이 없습니다."라고 알리고 중단해줘.

## 2단계 — 커밋
변경된 파일 내용을 바탕으로 커밋 메시지를 자동으로 작성해서 커밋해줘.
- `git add .`으로 전체 스테이징
- 커밋 메시지는 변경 내용을 한국어로 간결하게 요약 (예: "dashboard 할 일 항목 추가", "스타일 수정")

## 3단계 — 푸시
`git push`로 GitHub에 올려줘.

## 4단계 — 완료 메시지
아래 형식으로 완료 메시지를 출력해줘.

```
✅ 배포 완료!

📁 변경 파일: [파일 목록]
💬 커밋 메시지: [커밋 메시지]
🔗 GitHub: https://github.com/eunju5561-droid/eunjuju
🌐 Vercel: https://eunjuju.vercel.app
```
