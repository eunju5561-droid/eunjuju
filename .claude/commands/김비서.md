# 김비서 브리핑

아래 3단계를 순서대로 실행해줘.

---

## 1단계 — 데이터 읽기

다음 파일을 모두 읽어줘:

- `김비서-데이터/업무목록.csv`
- `김비서-데이터/주간일정.txt`
- `김비서-데이터/프로젝트현황.csv`
- `김비서-데이터/매출데이터.csv`
- `김비서-데이터/회의록.txt`

---

## 2단계 — dashboard.html 업데이트

`dashboard.html`을 읽고, 1단계에서 읽은 데이터로 아래 항목을 업데이트해줘.

- **헤더 날짜**: 오늘 날짜와 이번 주 범위로 수정
- **① 할 일 목록**: `업무목록.csv` 기준으로 전체 교체. 완료(done) 항목은 체크 처리, 우선순위(높음/보통/낮음)와 마감일 반영
- **② 이번 주 일정**: `주간일정.txt` 기준으로 이번 주 요일별 일정으로 교체
- **③ 프로젝트 진행률**: `프로젝트현황.csv` 기준으로 프로젝트명·진행률·담당자·상태·마감일 반영
- **④ 매출 요약**: `매출데이터.csv` 기준으로 총액·월별·카테고리별 수치 갱신

주의: 네비게이션 탭 메뉴(`.nav-tabs`)와 CSS 변수, 다크모드 코드는 절대 수정하지 마.

---

## 3단계 — 오늘의 브리핑 출력

대시보드 업데이트가 끝나면, 아래 형식으로 오늘의 브리핑을 출력해줘.

```
📅 오늘: [날짜 · 요일]

✅ 오늘 마감
  · [오늘 기한인 할 일 목록, 없으면 "없음"]

📌 오늘 일정
  · [주간일정 중 오늘 해당 항목, 없으면 "없음"]

⚠️ 이번 주 긴급 마감 (3일 이내)
  · [마감 임박 항목 목록]

🚀 주의 필요 프로젝트
  · [진행률 50% 미만이거나 마감 1주일 이내 항목]

💰 매출 현황
  · [총 매출 및 전월 대비 한 줄 요약]

💬 한마디
  · [데이터 기반으로 오늘 집중할 것 한 문장]
```
