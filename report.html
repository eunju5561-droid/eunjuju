✅ 잘한 점
강력한 차별화: 은행 연동 불필요
한국에서 금융 데이터 연동에 대한 거부감이 크다. "데이터는 기기에 저장"이라는 프라이버시 우선 접근은 핵심 경쟁력.
즉시 시작 — 가입 없이
회원가입 없이 대시보드를 바로 사용. 첫 마찰을 완전히 제거해 전환율을 높이는 전략.
AI 스크린샷 감지 — 실용적 혁신
영수증 하나 올리면 구독을 자동 인식. 가장 귀찮은 등록 과정을 AI로 해결한 UX 핵심 포인트.
SEO 블로그 전략 탁월
「Netflix 해지법」「ChatGPT vs Claude」등 검색 수요가 높은 키워드로 콘텐츠를 구성. 유기 트래픽 유입 설계 우수.
D-day + 캘린더 조합
각 구독에 D-10 · D-23 표시 + 월간 캘린더로 결제 일정을 이중으로 파악 가능. 실용적 UX.
완전 무료 모델
모든 기능이 무료(광고 운영). 구독 관리 앱에 돈을 쓰고 싶지 않은 타겟 심리와 정확히 일치.
⚠️ 개선점
로컬 저장 → 데이터 소실 위험
기기 교체·브라우저 캐시 삭제 시 모든 구독 데이터가 사라짐. 클라우드 동기(선택 opt-in) 옵션 필요.
소셜 프루프 전무
홈에 사용자 수·리뷰·별점이 전혀 없음. 신규 방문자 신뢰 형성 어려움. 간단한 숫자라도 표기 권장.
블로그가 랜딩페이지를 침식
홈 하단에 블로그 글 전체가 펼쳐짐. 앱 전환에 집중해야 할 페이지가 콘텐츠 페이지처럼 보임.
회사명과 서비스 간 톤 불일치
운영사명 「주식회사 헬로브이알」은 VR 기업 이미지. 금융·구독 관리 앱의 신뢰성과 미스매치가 발생할 수 있음.
